ACADEMIC PROJECT

DriveSafe AI

DriveSafe AI is an academic prototype combining web development, computer vision and machine learning to investigate real-time driver drowsiness detection through webcam-based eye-state analysis.

Educational Prototype Disclaimer: This application is an educational prototype and is not a certified automotive safety system.

Primary Technology Stack

  • Frontend: React 18, TypeScript, Tailwind CSS / HTML5, CSS3, JavaScript
  • Backend: Python, Flask
  • Computer Vision: OpenCV, MediaPipe (Planned Phase 3)
  • Machine Learning: TensorFlow/Keras, NumPy, Scikit-learn (Planned Phase 5/6)

Phase 3 Implementation

Browser-side MediaPipe FaceLandmarker integration for ultra-low latency, real-time face detection, and left/right eye localization, replacing the need for server-side OpenCV processing.
