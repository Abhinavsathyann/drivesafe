# ML Dataset Directory (Phase 4)

This directory will store dataset acquisition and preparation scripts in **Phase 4**.

### Planned Datasets:
* MRL Eye Dataset (Large-scale dataset of human eye images)
* CEW (Closed Eyes in the Wild) dataset

### Planned Structure:
* `raw/`: Unprocessed extracted eye patches
* `processed/`: Normalized, resized grayscale patches (24x24 or 32x32)
* `splits/`: `train`, `val`, `test` splits
